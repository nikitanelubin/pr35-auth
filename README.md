# Практическая работа №35. Роли и доступ: простая авторизация и защита роутов

Вариант 19 - возможность смены пароля (имитация: просто сообщение «Пароль изменён»).

## Структура

```
src/
  stores/
    auth.js                 - store авторизации: токен, роль, логин, login/logout/validateToken/changePassword
  pages/
    LoginPage.vue           - вход, после входа возврат на страницу из ?redirect=
    ProfilePage.vue         - профиль (user и admin), кнопка админки видна только admin
    AdminPage.vue           - панель администратора (только admin), запрос с токеном в заголовке Authorization
    ChangePasswordPage.vue  - вариант 19: смена пароля
  router/
    index.js                - маршруты и guard: проверка входа, ролей и guestOnly
  App.vue                   - шапка со статусом входа, RouterView
  main.js                   - подключение Pinia и роутера
```

## Маршруты

| Путь | Кому доступно |
|------|---------------|
| `/login` | только гостям (вошедшего перекидывает в профиль) |
| `/profile` | `user` и `admin` |
| `/admin` | только `admin` (user перекидывается в профиль) |
| `/change-password` | `user` и `admin` |

Демо-учётные записи: `admin / admin123`, `user / user123`

## Вариант 19: смена пароля

- В профиле кнопка «Сменить пароль» ведёт на защищённую страницу `/change-password`
- Форма: текущий пароль, новый пароль, повтор нового пароля
- Проверки на странице: все поля заполнены, новый пароль не короче 6 символов, новые пароли совпадают
- Action `changePassword` в store проверяет, что текущий пароль верный и что новый отличается от текущего (иначе выбрасывает ошибку)
- Если всё верно - сообщение «Пароль изменён». Это имитация: сервера нет, поэтому новый пароль никуда не сохраняется и входить по-прежнему нужно со старым

## Что проверить

1. Открыть `/profile` без входа - перекидывает на `/login`
2. Войти как `user` - профиль, кнопки «Перейти в панель администратора» нет; `/admin` перекидывает в профиль
3. Войти как `admin` - есть кнопка админки, в админке «Запросить защищённые данные» загружает данные
4. «Сменить пароль»: ввести неверный текущий пароль - ошибка; ввести разные новые пароли - ошибка; всё верно - «Пароль изменён»
5. Открыть `/change-password` без входа - перекидывает на вход, после входа возвращает на смену пароля
